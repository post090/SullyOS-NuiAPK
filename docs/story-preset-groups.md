# 剧情预设自定义分组

在预设制作器的「专业版」首页输入分组名称，点「新增分组」。新分组可以为空；点进去后用「在本区新增提示词」添加内容。打开已有提示词后，可以用「移动到分组」调整所属分组。

自定义分组支持改名、整组上下移动和取消分组。取消分组保留全部提示词，重新放回未分组区域。内置预设需先点「复制调整」；「角色与世界」等系统连接位保留原有保护规则。

分组边界保存在原生预设的 `prompts[].section` 中（id / name / edge），随保存、复制、备份和 JSON 导入导出保留。边界不发送给模型，提示词仍按数组顺序发送；不带分组信息的旧预设照常显示为「自定义条目」。

剧情重写排除本剧情在角色时间线中的镜像，避免旧版本通过角色近期原文回流。生成成功后在一次事务中原位更新中央正文和镜像；请求失败、并发修改或删除时保留原状态。重写不会额外发起第二次模型请求。
